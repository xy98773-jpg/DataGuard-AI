十二、State设计

必须使用强类型 State。

禁止使用裸 dict 作为核心状态。

推荐：

TypedDict + Pydantic

DataGovernanceState

class DataGovernanceState(TypedDict):

    # 基础

    run_id: str

    user_request: str


    # 数据源

    source_type: str

    dataset_id: str



    # 数据理解

    schema_info: dict

    profile_result: dict

    evidence: dict



    # 质量问题

    issues: list



    # Agent计划

    cleaning_plan: dict



    # 执行状态

    execution_results: list



    # 验证

    validation_result: dict



    # Human Loop

    approval_status: str



    # Workflow

    current_node: str

    iteration: int



    # Trace

    trace_id: str

十五、Agent Prompt规范

所有 Agent Prompt 必须独立文件管理。

目录：

    supervisor.md

    profiler.md

    inspector.md

    planner.md

Supervisor Prompt

Role:

You are Supervisor Agent.


Your responsibility:

Understand user goal.

Select workflow route.

Decide next node.



You cannot:

- modify data
- execute tools


Output JSON only.


Inspector Prompt

Role:

You are Data Quality Inspector Agent.


Goal:

Analyze dataset evidence.

Identify quality problems.


Rules:

1.
Only use provided evidence.

2.
Never invent data.

3.
Never modify dataset.

4.
Every issue requires evidence.


Output:

IssueReport JSON.


Planner Prompt

Role:

You are Cleaning Planner Agent.


Goal:

Generate safe cleaning plan.


Rules:

1.
Only use registered tools.

2.
Respect risk policy.

3.
Do not execute actions.

4.
Return structured JSON.


十六、Tool Registry设计

系统必须实现 Tool Registry。

禁止：

大量 if else 判断。

Tool Interface

所有 Tool 必须实现：
python:


class BaseTool:


    name:str


    description:str


    risk_level:str



    def execute():

        pass

Registry

pythn:

class ToolRegistry:


    tools={}



    def register(tool):

        self.tools[tool.name]=tool



    def get(name):

        return self.tools[name]
