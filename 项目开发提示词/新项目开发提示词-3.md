# 三十二、数据库设计

系统内部数据库使用：

SQLite

目的：

保存：

-   Agent运行记录
-   Workflow状态
-   Trace
-   Issue
-   Plan
-   Approval
-   Validation

外部企业数据库：

MySQL/PostgreSQL

作为 Data Source。

两者必须隔离。

三十三、数据库表设计 1. datasets

保存数据源信息。 SQL语句: CREATE TABLE datasets(

id TEXT PRIMARY KEY,

filename TEXT,

source_type TEXT,

storage_path TEXT,

row_count INTEGER,

column_count INTEGER,

created_at DATETIME

); 字段说明： source_type:

file

web

database

2.  workflow_runs

记录一次 Agent 执行。 SQL语句: CREATE TABLE workflow_runs(

id TEXT PRIMARY KEY,

dataset_id TEXT,

goal TEXT,

status TEXT,

current_node TEXT,

iteration INTEGER,

trace_id TEXT,

created_at DATETIME

); 状态： PENDING

RUNNING

WAITING_APPROVAL

SUCCESS

FAILED 3. dataset_profiles

保存数据分析结果。 SQL语句: CREATE TABLE dataset_profiles(

id TEXT PRIMARY KEY,

dataset_id TEXT,

schema JSON,

statistics JSON,

patterns JSON

); 4. issues

保存 Agent 发现的问题。 SQL语句: CREATE TABLE issues(

id TEXT PRIMARY KEY,

run_id TEXT,

issue_type TEXT,

column_name TEXT,

severity TEXT,

confidence FLOAT,

affected_rows INTEGER,

evidence JSON

); 5. cleaning_plans

保存 Planner 输出。 SQL语句: CREATE TABLE cleaning_plans(

id TEXT PRIMARY KEY,

run_id TEXT,

plan JSON,

risk_level TEXT,

created_at DATETIME

); 6. executions

记录 Tool 执行。 SQL语句: CREATE TABLE executions(

id TEXT PRIMARY KEY,

run_id TEXT,

tool_name TEXT,

input JSON,

output JSON,

status TEXT,

latency FLOAT

); 7. validations

保存结果验证。 SQL语句: CREATE TABLE validations(

id TEXT PRIMARY KEY,

run_id TEXT,

before_score FLOAT,

after_score FLOAT,

result TEXT,

details JSON

); 8. trace_events

Agent 可观测核心。 CREATE TABLE trace_events(

id INTEGER PRIMARY KEY,

run_id TEXT,

node TEXT,

event_type TEXT,

input JSON,

output JSON,

latency FLOAT,

tokens INTEGER,

status TEXT,

created_at DATETIME

); 9. approvals

Human-in-loop。 SQL语句: CREATE TABLE approvals(

id TEXT PRIMARY KEY,

run_id TEXT,

operation TEXT,

status TEXT,

operator TEXT,

created_at DATETIME
